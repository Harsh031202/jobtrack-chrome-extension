# JobTrack — Intelligent Job Application Tracker

==========================How to Load into Chrome===============================
1. Open Google Chrome and navigate to chrome://extensions/.
2. Toggle on Developer mode in the top right corner.
3. Click Load unpacked.
4. Select the dist folder from this repository.
5. Pin the JobTrack icon in your Chrome toolbar.
6. Browse any job listing (e.g. LinkedIn, Indeed, Greenhouse, Lever, or company career page) and click "Track this application" or press Alt+Shift+J.
